# Hotel AI Booking — демо-проект

MVP веб-приложения, демонстрирующего интеграцию языковой модели GigaChat с данными бронирования.
https://d5d54m5skt4h0crjru7t.kocrdvxt.apigw.yandexcloud.net/

## Функциональность
- Переключение статуса получения паспорта.
- Отправка сообщения гостя.
- Ответ ИИ-агента (GigaChat-2) с учётом статуса паспорта.
- Ведение краткой истории диалога.
- Кликабельные ссылки в ответах.

## Технологии
- Python 3.12, Flask
- HTML/CSS/JavaScript
- GigaChat API (Sber)

## Структура
См. дерево репозитория.

## Установка и запуск локально
1. Создайте виртуальное окружение и активируйте его.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Скопируйте `.env.example` в `.env` и укажите ваш `AUTHORIZATION_KEY`.
4. Запустите: `python run.py`.
5. Откройте http://localhost:5000.

## Проверка
- Без нажатия кнопки «Загрузить паспорт» отправьте «Как мне заселиться?» — ИИ попросит паспорт и даст ссылку.
- Нажмите кнопку, отправьте «Что мне делать дальше?» — ИИ скажет про оплату залога.
- Повторные вопросы должны сохранять контекст статуса.

## Примечание
Проект создан в демонстрационных целях. Для production требуется доработка безопасности и хранения состояния.
